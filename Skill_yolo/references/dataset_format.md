# YOLO 数据集目录结构与格式规范

## 标准目录结构

```
dataset/
├── images/
│   ├── train/              # 训练图片（.jpg / .png）
│   │   ├── Anumber_00001.jpg
│   │   ├── black_00001.jpg
│   │   └── ...
│   └── val/                # 验证图片
│       ├── Anumber_00001.jpg
│       └── ...
└── labels/
    ├── train/              # 训练标签（.txt，与图片一一对应）
    │   ├── Anumber_00001.txt
    │   ├── black_00001.txt
    │   └── ...
    └── val/                # 验证标签
        ├── Anumber_00001.txt
        └── ...
```

## YOLO 标签格式（TXT）

每个图片对应一个同名 `.txt` 文件，内容为每行一个目标：

```
class_id x_center y_center width height
```

### 坐标说明

| 字段 | 范围 | 说明 |
|------|------|------|
| class_id | 0 ~ (nc-1) | 类别索引，从 0 开始 |
| x_center | 0.0 ~ 1.0 | 目标中心点 X 坐标（相对于图片宽度的归一化值） |
| y_center | 0.0 ~ 1.0 | 目标中心点 Y 坐标（相对于图片高度的归一化值） |
| width | 0.0 ~ 1.0 | 目标宽度（相对于图片宽度的归一化值） |
| height | 0.0 ~ 1.0 | 目标高度（相对于图片高度归一化值） |

### 示例

假设图片尺寸 1920x1080，有一个目标（类别 1，即 black）在像素坐标 (960, 540)，宽 400，高 300：

```
x_center_norm = 960 / 1920 = 0.5
y_center_norm = 540 / 1080 = 0.5
width_norm    = 400 / 1920 ≈ 0.208
height_norm   = 300 / 1080 ≈ 0.278
```

对应 txt 文件内容：
```
1 0.500 0.500 0.208 0.278
```

## 文件命名规范

| 规范 | 要求 | 示例 |
|------|------|------|
| 前缀 | 英文，无空格，无特殊字符 | `Anumber_`, `black_` |
| 序号 | 5 位数字，补零 | `00001`, `00921` |
| 命名格式 | `{prefix}_{number:05d}` | `black_00001.jpg` |
| 图片格式 | `.jpg` 或 `.png` | `.jpg` 更通用 |
| 标签格式 | `.txt`，与图片同名 | `black_00001.txt` |

## 图片命名规范（按靶分类）

| 靶 | 颜色 | 文件前缀 | 示例 |
|----|------|---------|------|
| A | 数字靶 | `Anumber` | `Anumber_00001.jpg` |
| B | 黑色靶 | `black` | `black_00001.jpg` |
| C | 蓝色靶 | `blue` | `blue_00001.jpg` |
| D | 黄色靶 | `yellow` | `yellow_00001.jpg` |

## 数据集校验清单

- [ ] images/train 和 images/val 均存在
- [ ] labels/train 和 labels/val 均存在（标注后）
- [ ] 每张图片都有对应的同名 .txt 标签文件
- [ ] 所有坐标均为 0.0~1.0 归一化值
- [ ] class_id 在 0~(nc-1) 范围内
- [ ] data.yaml 中的 nc 与实际类别数一致
- [ ] names 字典键连续（0, 1, 2, ...）
