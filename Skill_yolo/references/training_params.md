# YOLOv8 训练参数详解与调优建议

## 基础训练命令

```bash
yolo detect train data=data.yaml model=yolov8n.pt epochs=100 imgsz=640 device=0
```

## 参数详解

### data
- **说明**：data.yaml 配置文件路径
- **建议**：使用绝对路径或相对于运行命令的路径

### model
| 模型 | 参数量 | 速度 | 精度 | 适用场景 |
|------|--------|------|------|---------|
| `yolov8n.pt` | ~3.2M | 最快 | 基础 | 快速测试流程、嵌入式 |
| `yolov8s.pt` | ~11.2M | 快 | 较高 | 通用场景（推荐起步） |
| `yolov8m.pt` | ~25.9M | 中 | 高 | 精度要求高 |
| `yolov8l.pt` | ~43.7M | 慢 | 更高 | 大数据集 |
| `yolov8x.pt` | ~68.2M | 最慢 | 最高 | 最高精度需求 |

**推荐流程**：先用 `yolov8n.pt` 验证整个流程通畅，再换 `yolov8s.pt` 或更大模型正式训练。

### epochs
- **说明**：训练轮数
- **默认值**：100
- **调优建议**：
  - 数据量少（<1000张）：100~200 轮
  - 数据量中（1000~5000张）：50~100 轮
  - 数据量大（>5000张）：30~50 轮
- **早停**：配合 `patience` 参数防止过拟合

### imgsz
- **说明**：输入图片尺寸（正方形）
- **默认值**：640
- **调优建议**：
  - 小目标检测：可用 1280（配合更大模型）
  - 常规场景：640
  - 速度优先：320

### batch
- **说明**：批次大小
- **默认值**：16
- **调优建议**：根据显存调整
  - 8GB 显存：batch=16
  - 12GB+ 显存：batch=32
  - 显存不够：batch=8 或更低

### device
- **说明**：训练设备
- **选项**：
  - `0`：使用第一块 GPU
  - `cpu`：使用 CPU（极慢，不推荐）
  - `0,1`：使用多 GPU（需多卡机器）

### patience
- **说明**：早停耐心值（验证集 mAP 不提升时等待的轮数）
- **默认值**：50
- **建议**：20~50，防止过拟合

### project
- **说明**：项目目录名（训练结果保存位置）
- **建议**：固定项目名便于管理

### name
- **说明**：本次运行的子目录名
- **建议**：包含模型名或实验描述

### 其他常用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `optimizer` | SGD | 优化器，也可选 Adam、AdamW |
| `lr0` | 0.01 | 初始学习率 |
| `lrf` | 0.01 | 最终学习率 = lr0 * lrf |
| `momentum` | 0.937 | 动量 |
| `weight_decay` | 0.0005 | 权重衰减 |
| `warmup_epochs` | 3.0 | 预热轮数 |
| `close_mosaic` | 10 | 在最后 N 轮关闭马赛克增强 |
| `resume` | False | 从上次中断处继续训练 |
| `pretrained` | True | 使用预训练权重 |

## 输出指标解读

### 训练阶段（每 epoch 输出）

```
epoch    loss    metrics          lr
  1/100  2.341   box:1.23 cls:0.89 dfl:1.02  0.010
```

| 指标 | 说明 |
|------|------|
| box_loss | 边界框回归损失（越小越好） |
| cls_loss | 分类损失（越小越好） |
| dfl_loss | 分布焦点损失（越小越好） |
| mAP50 | mAP@IoU=0.50（越大越好） |
| mAP50-95 | mAP@IoU=0.50:0.95（越大越好） |

### 验证阶段（每个 epoch 末）

```
Results saved to runs/detect/train{index}/results.png
```

### 最终模型选择

训练完成后，`runs/detect/{project}/{name}/weights/` 目录中会有两个权重文件：

| 文件 | 说明 | 使用场景 |
|------|------|---------|
| `best.pt` | 验证集 mAP 最高的模型 | 推理/部署 |
| `last.pt` | 最后一轮的模型 | 断点续训 |

## 调优建议

### 数据量少（< 500 张/类）

1. 增加 epochs（200~300）
2. 使用数据增强（YOLOv8 默认开启 mosaic、mixup）
3. 关闭部分增强（`close_mosaic=20` 减少到 5）
4. 使用 `mosaic=0.5` 降低 mosaic 比例
5. 使用更大模型（s 或 m）

### 漏检多（Recall 低）

1. 降低 confidence 阈值
2. 增大 imgsz
3. 检查标注质量（是否漏标）
4. 增加训练数据

### 误检多（Precision 低）

1. 提高 confidence 阈值
2. 检查标注质量（是否错标）
3. 增加不同场景的数据
4. 使用更严格的 NMS（`iou=0.5` 降到 `0.3`）

### 过拟合

1. 开启早停（`patience=20`）
2. 增加数据增强
3. 降低模型复杂度
4. 使用 `weight_decay=0.01`
